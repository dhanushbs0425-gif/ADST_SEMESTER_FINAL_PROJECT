About SeedSense AI

System Architecture & Technical Overview

SeedSense AI is an autonomous, full-stack Deep Learning & Computer Vision web application designed for agricultural seed classification, quality inspection, and defect detection.

Two-Stage AI Classification Workflow
Input Seed Image / Tray Image
   │
   ├──► OpenCV Denoising & Watershed Segmentation
   │       └──► Individual Seed Extraction & Bounding Boxes
   │
   ├──► STAGE 1: Seed Species Classification (MobileNetV3)
   │       ├──► Rice / Maize / Soybean
   │       └──► Unknown / Unsupported Check (Confidence < 0.55)
   │
   └──► STAGE 2: Seed Quality & Defect Type Classification (MobileNetV3)
           ├──► Healthy vs Defective / Damaged
           └──► Defect Type: Broken, Skin-damaged, Spotted, Discolored
Computer Vision & Feature Engineering
  • Pre-processing: Gaussian Denoising, Otsu Thresholding, Morphological Opening & Closing.
  • Segmentation: OpenCV Distance Transform + Watershed Algorithm for separating touching seeds.
  • Feature Extraction: 12 Color Features (RGB/HSV mean & std), 8 Shape Features (Area, Perimeter, Aspect Ratio, Circularity, Solidity, Extent), 16 Texture Features (GLCM Contrast, Homogeneity, Energy, Correlation).
  • ML Classifiers: SVM, Random Forest, K-Nearest Neighbors (KNN), Logistic Regression.
  • Deep Learning Architecture: PyTorch Transfer Learning with MobileNetV3 Small.
System Features
  • Single & Tray/Batch Image Analysis
  • Visual Bounding Box Annotations with Confidence Scores
  • SQLite Database History Storage
  • Downloadable PDF Reports generated via ReportLab
  • Empirical performance dashboard with zero data fabrication
